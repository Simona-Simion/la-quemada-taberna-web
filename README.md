

# La Quemada Taberna Web

Web one page para **La Quemada Taberna**, una taberna en Zaragoza.

El objetivo del proyecto es presentar el local, su historia, la carta, las reseñas reales, la ubicación y la identidad visual de la taberna de forma clara, rápida y cuidada.

## Estado del proyecto

Proyecto en desarrollo.

Primera versión enfocada en una web estática, rápida y fácil de mantener, sin backend ni base de datos.

## Stack

- React
- Vite
- JavaScript
- Tailwind CSS

## Funcionalidades previstas

- Página one page responsive
- Hero con identidad de marca
- Historia de La Quemada y origen del nombre
- Cartas en PDF: comida y vinos
- Sección visual de carta
- Fotos del local, platos y ambiente
- Reseñas reales de clientes
- Ubicación y enlace a Google Maps
- Diseño oscuro, cálido y rústico moderno
